* titles

A web service for describing the content of internet services. It takes in a url and returns a title.

** Features

- Supported protocols: HTTP
- Customized extraction mechanisms for various services.
- Supports multiple languages.
- Built with Python async.
- Includes tests that can be used to ensure that each service is parsed properly.

- [browser] Uses a real web browser through playwright as a fallback.
- [media] Supports many content types: HTML, PDF, PNG, JPEG, MP3, ACC, FLAC and more.
- [explicit] Detects explicit content using metadata and ML models.

- External API for non-title responses.

** Usage

Install, configure and run the service (see below). Then you can make GET requests like the one below:

#+BEGIN_SRC text
  -> http://127.0.0.1:11557/title?u=https://google.com
  <- {"t":"Google"}
#+END_SRC

** Installation

#+BEGIN_QUOTE
Run the following steps inside a virtual environment. See: https://docs.python.org/3/library/venv.html
#+END_QUOTE

You can install this library using pip:
#+BEGIN_SRC sh
  pip install "git+https://github.com/hyperimpose/titles.git@master"
#+END_SRC

or you can clone it:
#+BEGIN_SRC sh
  git clone https://github.com/hyperimpose/titles.git
  cd titles
  pip install -e .
#+END_SRC


*** Optional Dependencies
Some of the features above are optional. You can tell pip which features you want by using the syntax
~[media,explicit]~ after the installation url:

#+BEGIN_SRC sh
  pip install "git+https://github.com/hyperimpose/titles.git@master"[browser,explicit,media]
#+END_SRC

The availability of those dependencies is checked once when titles is imported.
When an optional dependency is missing the library will log a warning to inform you about the fact.

Table of available optional features:
|----------+-----------------------------------------------------------|
| Name     | Description                                               |
|----------+-----------------------------------------------------------|
| browser  | Use a real web browser as a fallback to get more results. |
| media    | Extract extra information from various media files.       |
| explicit | Use a local AI model to detect explicit media             |
|----------+-----------------------------------------------------------|

**** Browser installation
If you install with the browser option, you will need to also install firefox through playwright:
#+BEGIN_SRC sh
  playwright install firefox
#+END_SRC

**** Explicit video detection
The explicit service can provide video support. Some extra runtime dependencies are needed for this to work.
The availability of those dependencies is checked once when the service is started.
When a runtime dependency is missing the library will log a warning to inform you about the fact. 

Table of extra runtime dependencies:
|---------+---------------------------------------|
| Name    | Description                           |
|---------+---------------------------------------|
| ffmpeg  | Enables explicit detection of videos. |
| ffprobe | MUST be installed with ~ffmpeg~.      |
|---------+---------------------------------------|

** Running

After installing the library you can run it either as a module:

#+BEGIN_SRC sh
  python -m titles
#+END_SRC

or from the project's root directory:

#+BEGIN_SRC sh
  python titles
#+END_SRC

*** Configuration

The service can load configuration options either from the environment or a ~.env~ file.

Read [[./titles/config.py][config.py]] for the available configuration options.

** API

Only GET methods are provided. They return JSON values:

|-----------------+--------------------------------------------+----------------------------------------------|
| Path            | Parameters                                 | Returns                                      |
|                 |                                            |                                              |
|-----------------+--------------------------------------------+----------------------------------------------|
| /title          | u: The url to retrieve the title for       | An object. See the Title class in [[./titles/common.py][common.py]]. |
|                 | (optional) lang: An Accept-Language header |                                              |
|-----------------+--------------------------------------------+----------------------------------------------|
| /duckduckgo     | q: The query to search for                 | A list of objects. See [[./titles/as_http/external/duckduckgo.py][duckduckgo.py]].        |
|-----------------+--------------------------------------------+----------------------------------------------|
| /youtube/search | q: The query to search for                 | A list of objects. See [[./titles/as_http/external/youtube.py][youtube.py]]            |
|                 | (optional) lang: An Accept-Language header |                                              |
|-----------------+--------------------------------------------+----------------------------------------------|
